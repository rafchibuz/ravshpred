# RAVSHANN Предложка

Локальный frontend-прототип сервиса для отправки, модерации и показа YouTube-видео на стриме.

## Запуск локально

Требуется Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска откройте `http://localhost:5173/`.

Доступны демонстрационные роли:

- `http://localhost:5173/?role=moderator` — экран модератора;
- `http://localhost:5173/?role=owner` — управление проектом.

Вход через Twitch пока имитируется локально. Данные и действия хранятся только в состоянии браузера; backend, OAuth и база данных будут добавлены следующим этапом.

## Проверка сборки

```bash
pnpm build
```

## Структура

- `src/main.jsx` — React-компоненты и демо-сценарии;
- `src/styles.css` — адаптивная темная тема;
- `assets/banner.png` — фирменный баннер из ТЗ.
