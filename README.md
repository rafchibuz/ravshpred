# RAVSHANN Предложка

Локально запускаемый сервис предложений YouTube-видео: публичная лента, Twitch-вход,
голоса, очередь модерации, отметка «Отсмотрено», новости проекта с комментариями и
отдельная панель основателя.

## Быстрый локальный запуск

Нужен Docker Desktop:

```powershell
docker compose --env-file .env -f deploy\compose.yaml up -d --build
```

После запуска:

- `http://localhost:8088/` — единственный адрес сайта. Гость видит публичную
  ленту, а права пользователя, модератора и владельца появляются только после
  настоящего Twitch-входа.

Состояние контейнеров:

```powershell
docker compose --env-file .env -f deploy\compose.yaml ps
docker compose --env-file .env -f deploy\compose.yaml logs --tail=100
```

## Конфигурация

Скопируйте `.env.example` в `.env`. Для настоящего Twitch-входа укажите
`TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` и зарегистрируйте callback:

`http://localhost:8088/api/auth/twitch/callback`

Пользователь сначала должен один раз войти через Twitch. После этого основатель
может назначить его модератором по точному Twitch-нику.

Twitch-пользователь с ником из `OWNER_TWITCH_LOGIN` автоматически получает роль
`owner` при входе. По умолчанию это `rafchibiskus`. Отдельного закрытого входа
основателя нет. Для production также укажите неизменяемый числовой
`OWNER_TWITCH_ID`: он имеет приоритет над ником и защищает роль при переименовании
Twitch-аккаунта.

Для реальных просмотров, лайков и длительности YouTube нужен `YOUTUBE_API_KEY`.
Без ключа заголовок, автор и превью берутся через YouTube oEmbed, а вместо
неизвестных числовых метрик интерфейс показывает `—`. При наличии ключа метаданные
новых видео загружаются сразу, а существующие записи автоматически обновляются
при запуске API и затем каждые 12 часов.

Тестовых ролей, специальных QA-ссылок и обхода Twitch-авторизации в проекте нет.

PostgreSQL автоматически архивируется отдельным контейнером: 7 ежедневных и
4 еженедельных копии с SHA-256 проверкой. Инструкции проверки и восстановления
находятся в `deploy/README.md`.

Вкладка «Новости» доступна всем посетителям. Публиковать и удалять новости может
только основатель; оставлять комментарии могут пользователи с Twitch-сессией.
Автор удаляет свой комментарий, основатель — любой. Правила, политика
конфиденциальности и условия использования доступны в футере сайта.

## Закрытый кастинг

В панели основателя есть блок «Доступ к кастингу». Укажите точный Twitch-ник
пользователя, который уже хотя бы один раз вошёл на сайт. После выдачи доступа у
него появится пункт «Кастинг». Основатель имеет доступ всегда.

Исходный Excel загружается владельцем в этом же блоке панели. Анкеты сохраняются
в закрытой базе и не попадают в публичный репозиторий. Новая загрузка заменяет
текущий список и сбрасывает выставленные оценки. Для каждого участника хранится
одна общая оценка от 1 до 10 с шагом 0,5: её последнее изменение сразу видят
владелец и все допущенные проверяющие. YouTube и YouTube Shorts воспроизводятся внутри
страницы через `youtube-nocookie.com`; отдельная вкладка и API-ключ не нужны. Если
вместо видеоссылки участник оставил текст, он отображается прямо в видеоблоке.
